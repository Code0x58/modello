Examples
========

The examples run from a checkout or an extracted source distribution. They
demonstrate applications of Modello and explore possible higher layers; their
helpers and domain models have evolving interfaces.

The installed wheel contains the core ``modello`` package. Start with the
:doc:`modeling API </api>` and :doc:`nested-model guide </nesting>` for its public
interfaces.
